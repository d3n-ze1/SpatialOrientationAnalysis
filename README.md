# Spatial Orientation Test Analysis

Python tool for analyzing data from the Spatial Orientation Test (SOT).

## Features

- Reads participant .txt files
- Extracts AngularError values
- Calculates mean angular error per participant
- Sorts and Exports results to CSV

## Usage

Place participant files in:

data/

Run:

`python analyze.py`

Results will be written to:

output/scores.csv
